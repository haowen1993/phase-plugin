# phase-plugin

[phase.rs](https://phase-rs.dev) 的书签插件，零安装。
1. **大学院废墟卡图**、
2. **替换阶段图标**。

**👉 [打开安装页](https://haowen1993.github.io/phase-plugin/)** —— 把按钮拖到书签栏，在 phase-rs.dev 点一下（刷新或重开页面后要再点一次）。
